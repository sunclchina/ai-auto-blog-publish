# A-Blog · AI 全自动博客 WordPress 插件

> 装进 WordPress 就能**全自动日更**的 AI 博客系统：自动选题 → AI 写作 → 自动配图 → 定时发布，无人值守。

A-Blog 是一个**自足的功能插件**：数据、调度、素材、生成全部在 WordPress 内完成，可运行于本地、云端、任何 WordPress 环境（IIS / Nginx / Apache 均可），不依赖任何外部服务。

支持五个栏目：**股票（A股复盘）、IT、国学、读书（书评）、行业**——栏目与博客**已定义分类**一一对应，发布时按分类名精确匹配，绝不创建新分类。

## 📦 功能总览

### ✍️ 全自动写作流水线

选题 → 提纲 → 初稿 → 人性化改写 → SEO 标题/描述 → 配图 → 定时发布，七步全自动；支持股票复盘（真实行情数据驱动、禁止编造）、IT、国学、读书、行业五栏目。

### 🎛️ 开关控制

- **AI 写文总开关**：关闭后不建队列、不生成（WP-Cron 调度与 REST 提交均拦截）
- **栏目开关**：五个栏目独立开关，对应博客已定义分类（股票 / IT / 国学 / 读书 / 行业）
- **配图开关**：关闭则纯文字发布，不上传封面
- **发布开关**：关闭则仅存草稿，不直接发布
- **摘要 / 评论 / 话题开关**（v1.5.51 新增）：开启后文章完成时自动生成 AI 摘要、5 条评论、热门话题并归档（WP-Cron 延迟执行，不拖慢发布请求）

### 📋 任务队列 + 备用选题池

- **备用选题池**：可编辑、删除、排序，一键「列入计划 / 立即完成」
- **每日发文篇数**：严格按设置控制每天列入计划的任务数量（1-10 篇，栏目轮转选取，不固定栏目霸占额度）；**未发文章不补发**（错过即不补建）
- **备用选题每日新增数**：按栏目配置，每日自动从内置素材（RSS/诗词/书单/行业概念）补入选题池，一天一次、去重自动、池子上限 20
- **计划任务**：全部任务列表（按发布时间排序），支持「立即完成 / 重写（重新生成并覆盖原文章）/ 删除 / 清空全部」
- **重写机制**：已发布任务可一键重写——重新生成内容并**覆盖原文章**（保留文章 ID，不产生重复）

### 🧰 AI 工具箱（批量）

- **摘要**：为文章生成摘要（post_excerpt + SEO Meta）
- **评论**：AI 生成自然评论，状态遵循「评论必须经人工批准」设置（开启则进审批，关闭则直接显示）
- **热门话题**：分析文章生成话题，注册 `abp_topic` 分类法并归档
- **AI 配图**：本地生成封面（OpenAI 兼容文生图 / 通义万相），自动上传媒体库并设为特色图

### 🖥️ 后台操作台

统一管理：开关列表、模型配置、每日篇数/选题池配置、任务队列、选题池、工具箱、日志、GitHub 自动更新。所有数据存 WP 数据库（`wp_abp_tasks` / `wp_abp_pool`），零代理零外联。

### 🔒 安全与查重

- API Key / Token 仅存 WP option，**不入日志、不入库**
- REST 接口全部 Bearer Token 鉴权
- 任务指纹查重（simhash）防重复发布；**复盘按日期查重**（兼容 ISO / 中文日期格式），已有该复盘日文章自动删旧覆盖重做
- 摘要策略：只接受 AI 生成/手工摘要，不拿正文截取充数

## 🚀 快速开始

1. 下载最新 Release（`dist/ai-auto-blog-publish-vX.Y.Z.zip` 或 GitHub Releases）
2. 后台 → 插件 → 上传安装 / 启用
3. 配置模型 API（设置页）→ 开启栏目 → 设置每日篇数 → 每日调度自动跑

## 🔄 更新机制

- 后台操作台「检查更新」按钮（GitHub Release 通道，api.github.com 直连下载）
- 插件主文件版本号与 Release tag 对应

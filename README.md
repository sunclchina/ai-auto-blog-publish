# A-Blog · AI 全自动博客 WordPress 插件

> 装进 WordPress 就能**全自动日更**的 AI 博客系统：自动选题 → AI 写作 → 自动配图 → 定时发布，无人值守。

A-Blog 是一个**自足的功能插件**：数据、调度、素材、生成全部在 WordPress 内完成，可运行于本地、云端、任何 WordPress 环境（IIS / Nginx / Apache 均可），不依赖任何外部服务。

支持五个栏目：**A股复盘、IT技术、国学、书评、行业分析**。

**分类归并原则**：从选题到写作再到发布，只使用博客**已定义过的分类**——A股复盘→`股市`、IT技术→`IT`、国学/书评→`读书`、行业分析→`行业`；任何别名（industry / it-notes / IT技术笔记 等）一律归入对应分类，绝不创建新分类。

## 功能一览

### 📅 全自动调度（内置，无需系统定时任务）
- 每日自动建当日任务队列 → 到点生成 → 定时发布
- **错过补偿**：服务器关机/站点无访问错过的任务，开机后自动补建补写（错几天的复盘、文章一并补上，复盘用历史行情数据，不编造）
- 单篇可后台一键「立即完成」

### 🎯 智能选题（大模型选题 + 动态素材）
| 栏目 | 选题方式 | 素材源 |
|---|---|---|
| A股复盘 | 仅交易日；题目固定（日期+「A股市场：」+副标题） | 新浪/东财**实时行情**（历史补写用日K） |
| IT技术 | AI 从候选中挑 | 内置高频问题池 + 可配 **RSS** 动态抓取 |
| 国学 | AI 挑（唐诗 50%/宋词 30%/古文 15%/节气 5%） | 唐诗三百首/宋词三百首**联网获取、每日更新** + 古文观止精选 |
| 书评 | 查重过滤后随机 | 本站图书目录抓取 → 热门书单兜底（已写书目自动排除） |
| 行业分析 | AI 挑 | Tavily 联网搜索热门行业/概念（可选 key） |

### ✍️ AI 写作
- 统一模型配置（A股/IT/国学/书评/行业共用一个模型），支持青简主题密钥自动探测
- 各栏目专属写作规范（复盘为定制版：7 大模块、数据密度、时效性、文风约束、风险提示）
- **数据精准、禁止编造**：行情数字必须来自采集素材，缺失字段如实标注

### 🖼️ AI 配图
- 后台批量「AI 配图」：按文章内容生成封面，自动上传媒体库并设为特色图
- 支持阿里百炼（wanx-v1 等）与 OpenAI 兼容生图服务

### 🗂️ 后台管理台
- 备用选题池：智能填充 / 增删改排 / 列入计划 / 立即完成
- 今日计划任务：指定/删除/立即完成/清空
- 任务日志、AI 工具箱（摘要/评论/热门话题）、模型探测、API Token

## 安装

1. 后台「插件 → 安装插件 → 上传插件」上传 `ai-auto-blog-publish-v1.5.29.zip`，激活
2. 激活即自动建表、注册调度，无需额外操作
3. 「AI 自动博客」设置页按需配置：
   - **AI 模型**（默认 deepseek-chat）与 DeepSeek API Key（或复用青简主题密钥）
   - 可选：图片 API 配置（AI 配图用）、Tavily API Key（行业分析用）、站点图书目录（书评选题用）、IT RSS 源
4. 生成 API Token（供生成引擎/外部调用）

**升级**：上传新 zip 覆盖即可，自动建表自愈；后台「自动升级」可一键检查 GitHub Release 更新。

## IIS 环境兼容（Windows 服务器）

IIS + FastCGI 对 URL 中的**中文路径按 GBK 解码（实际是 UTF-8）**，会导致中文 slug 的分类/标签链接访问 404（英文 slug 不受影响）。A-Blog 已内置两段兼容层（`wp-plugin/mu-plugins/`），IIS 环境部署时请将目录下两个文件复制到 `wp-content/mu-plugins/`：

| 文件 | 作用 |
|---|---|
| `ablog-iis-rest.php` | 将 REST 地址 `/wp-json/` 归一为 `?rest_route=`（IIS 无 URL Rewrite 时 REST 健康检查/接口可用） |
| `ablog-iis-category.php` | 中文 slug 分类链接改用 `?category_name=` 参数形式（绕开 IIS 中文路径乱码 404） |

> Nginx / Apache 环境无需此兼容层。

## 架构

```
WordPress + A-Blog 插件（主体：调度/选题/写作/发布/数据全部自足）
        │
        └── 可选：Python 伴生服务（专业流水线/行情深挖/Tavily 资讯增强，经 REST 协作）
```

- 插件在任何环境独立可用；Python 服务仅作可选增强，不部署也不影响日更
- 全部数据存 WordPress 数据库（任务表 / 选题池 / 日志），前端调用走 `?rest_route=` 形式（兼容 IIS）

## 复盘规则

- 标题 = 当日日期 +「A股市场」+「：」+ 副标题；副标题**正文后取**（先写正文，再提炼盘面特点），无备选题目
- 查重按标题日期；同日期已存在 → 覆盖重做
- 行情数据**联网获取**（实时接口/历史日K），数据精准、禁止编造、标注来源，文末附风险提示

## 安全

- API Key / Token 仅存 WP option，**不入日志、不入库**
- REST 接口全部 Bearer Token 鉴权
